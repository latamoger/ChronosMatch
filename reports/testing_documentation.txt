# ChronosMatch – Testing and Performance Documentation

**Project:** ChronosMatch: Zero-Copy High-Frequency Trading Engine

**Team Member:** Lata Moger  
**Role:** Testing & Performance Developer

## 1. Introduction

ChronosMatch is a trading engine project designed to match buy and sell orders using price-time priority.

My responsibility is to test the matching engine, measure its performance, identify defects, and prepare testing documentation.

## 2. Testing Objectives

- Verify correct buy and sell order matching.
- Check partial order execution.
- Verify price and time priority.
- Validate invalid order inputs.
- Test basic Flask API functionality.
- Measure order-processing performance.

## 3. Tools and Technologies

- Python
- unittest
- Flask test client
- VS Code
- CSV reports

## 4. Functional Testing Results

Seven matching-engine test cases were executed successfully.

**Result:** 7 Passed, 0 Failed.

## 5. API Testing Results
